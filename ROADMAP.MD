# Car Doctor project status

The project currently contains only the Next.js storefront and its static
assets. The backend has been removed and can be set up later.

## Frontend

- Responsive storefront, product and service pages, and administrator UI.
- Bundled demo catalog data and browser storage for frontend-only preview.
- API-dependent features require a backend and will not persist until one is
  added.

## Local setup

Run `npm install` and `npm run dev` from `frontend/`, or run
`docker compose up --build` from the repository root. See [README.md](./README.md)
for details.
